# 实机验收指南

对应版本：**v0.3.0（versionCode 5）**

v0.3.0 补齐了 PRD 剩余功能：**图片输入**（拍照 / 相册 / 多图）、**每日提醒**、
**分享花园**、**自定义标签**、**字体大小**、**进阶收集玩法**（进化花种 / 季节限定 /
隐藏款）、**时光轴搜索筛选**、**色彩对比度无障碍**、**仪式音效**。

---

## 一、安装哪个包

产物位于 `build/app/outputs/flutter-apk/`：

| 文件 | 体积 | 适用 |
| --- | --- | --- |
| `app-arm64-v8a-release.apk` | 18.6 MB | **绝大多数现代手机，优先装这个** |
| `app-armeabi-v7a-release.apk` | 16.1 MB | 较老的 32 位机型 |
| `app-x86_64-release.apk` | 20.1 MB | 模拟器 / x86 平板 |
| `app-release.apk` | 53.9 MB | 通用包，不确定机型时用它 |

安装方式：传到手机后点击安装，需在系统设置里允许「安装未知来源应用」。

> ⚠️ 当前 release 包沿用 **debug 签名**（`android/app/build.gradle.kts` 中的 TODO），
> 只用于实机验收，**不能上架**。正式发版前需要配置正式签名。

## 二、验收清单

### 1. 数据是否真正落盘（最重要）

| 步骤 | 预期 |
| --- | --- |
| 记一件开心事 → 选标签 → 保存 | 出现「种子已经入土 / 向日葵第 1 颗种子，再种 9 颗会长出下一朵花 / 花园养分 +10」 |
| 回到花园首页 | 土壤里出现 🌰，今日种下 = 1，养分进度条有少量填充 |
| **上滑划掉 App（或重启手机）后重新打开** | **种子仍在、今日种下仍为 1、养分不变** |
| 我的 → 隐私与数据 | 徽章显示 **「已加密」**，说明文案为「记录已本地加密，密钥由系统安全区托管」 |

旧版本（v0.1.0）关掉 App 数据就全没了；这一轮之后数据会留存。

### 2. 烧纸卷与「内容不可恢复」

| 步骤 | 预期 |
| --- | --- |
| 首页点「点燃纸卷」→ 写点字 | 底部按钮从「写点什么才能点燃」变为可用的「长按点燃引信」 |
| **长按**底部按钮不放（约 1.6 秒） | 进度条上升，文案在「别松手…」「就要着了…」之间变化 |
| 中途松手 | 进度**回退**，不留任何痕迹，内容仍可编辑，**不报错** |
| 长按到底 | 纸卷变黑缩短、火线自下而上推进 → 灰烬粒子**全部向下**飘入土壤 → 出现「已经变成花园的养分了 / 养分 +15」 |
| 回到首页 | 今日转化 = 1，养分比上一次多 **15**（种花是 +10，负向转化刻意不低于正向） |
| 时光轴 → 点今天 | 开心事内容**可见**；烧掉的纸卷只有一条灰底封条「已转化为养分 / 内容已随灰烬散去」，**没有任何入口能再看到原文** |

> 长按需要按住约 2.1 秒才会点燃：系统识别长按有 0.5 秒延迟，
> 之后才是 1.6 秒的进度条。松手只回退进度，不会有失败感。

### 3. 字体放大不溢出（无障碍）

去系统设置把「字体大小」调到最大，再逐页浏览花园 / 时光轴（周·月·年）/ 图鉴 / 我的 /
记录开心事 / 情绪纸卷 / 日期详情。

预期：**没有任何页面出现黄黑斜纹的溢出条**，文字自动换行或卡片自动变高。

### 4. 两处已修复的统计口径

| 位置 | 旧行为（错误） | 现行为 |
| --- | --- | --- |
| 我的 → 「已开花」 | 显示的是**植物总数**（与上一行文案重复） | 只统计真正开过花的数量 |
| 图鉴顶部「已收集 N 种花」 | 按「种下过」计数，与卡片剪影判定矛盾 | 与卡片一致：**开花才算收集** |

### 5. 图片输入（PRD 7.1.1 / 7.2.1）

| 步骤 | 预期 |
| --- | --- |
| 记录开心事 → 点「加张照片」 | 弹出「拍一张 / 从相册选」两个选项 |
| 从相册选 1-2 张 | 卡片里出现缩略图，右上角有 × 可删；按钮旁显示「还可放 N 张」 |
| 保存后回到首页 → 时光轴 → 点今天 | 记录下方出现图片，点开可全屏查看、双指缩放、左右翻页 |
| 情绪纸卷页同样操作后点燃 | 纸卷及其图片一起消失；时光轴只剩封条 |
| **图片是否加密** | 见下方「我已验证过的部分」——磁盘上找不到任何可直接打开的图片文件 |

### 6. 设置项（PRD Tab4）

| 设置项 | 预期 |
| --- | --- |
| **字体大小** | 拖动即时生效，下方预览同步变化；「恢复跟随系统」可回到 1.0 |
| **每日提醒** | 选时间 → 开启 → 系统询问通知权限；到点会收到一条温和的提醒。关掉后不再响 |
| **分享花园** | 弹出一张花园卡片预览 → 点分享 → 走系统分享面板（可存图/发微信） |
| **我的心情标签** | 点「新建标签」可加自定义标签（名字 + 图标 + 花种）；带 × 的能删，预设删不掉 |
| **仪式音效** | 开着时种子入土与点燃纸卷有轻音效；关掉后完全静音 |

### 7. 进阶收集玩法（PRD 7.1.3）

| 玩法 | 怎么验 |
| --- | --- |
| **季节限定** | 当前若不在 3-4 月，「美食」标签会置灰并显示「3-4 月可种」，点不动 |
| **进化花种** | 同一标签记满 30 条后，保存时会多一段「解锁了金向日葵」；此后该标签多出一个带 🌟 的选项，种下后花园里是金色的 |
| **隐藏款** | 连续记录满 21 天后，标签列表里会出现带 🌙 的「月光花」 |

### 8. 时光轴搜索与筛选（P2）

| 操作 | 预期 |
| --- | --- |
| 顶部搜索框输入关键词 | 立刻筛出含该词的记录（烧掉的纸卷搜不到，这是对的） |
| 点右侧 🏷️ 按钮 | 弹出标签多选面板；选几个后「应用」 |
| 应用后 | 周 / 月 / 年三个视图同时只剩命中的记录；下方显示当前条件与「清除筛选」 |

### 9. 启动不再黑屏

冷启动时若存储装配较慢，应先看到一帧奶油白的品牌过渡页（🌻 + 心情花园 + slogan），
而不是一片纯黑窗口。装配通常在几十毫秒内完成，多数情况下只是一闪而过。

## 五、构建方式

```bash
tool/build_android.sh          # 通用包
tool/build_android.sh --split  # 分 ABI 包
```

脚本只做一件事：把本机那套非标准路径（JDK 与 Android SDK 装在
`~/development/toolchain`）export 好。场景说明：

- **Flutter SDK** 位于 `~/development/flutter`，不在 PATH。
- **JDK 21 与 Android SDK** 位于 `~/development/toolchain/`。所需组件：
  `platform-tools`、`platforms;android-36`、`platforms;android-35`、
  `build-tools;36.0.0`、`build-tools;35.0.0`、`ndk;28.2.13676358`、`cmake;3.22.1`。
  - android-35 是 `path_provider_android → jni_flutter` 要求的编译目标；
  - cmake 是 `jni` 编译 JNI 用的。
- **Maven 仓库走阿里云镜像**：`maven.google.com` 在本网络下不可达。
  镜像配在三处——`android/settings.gradle.kts`、`android/build.gradle.kts`，
  以及全局 `~/.gradle/init.d/00-china-mirrors.gradle`。
  最后那处是必需的：Flutter 的 included build（`packages/flutter_tools/gradle`）
  自带 settings 且用 `FAIL_ON_PROJECT_REPOS` 禁止项目级仓库，只能从 Gradle 全局层注入。
- **`android/gradle.properties` 里关掉了 AGP 的 SDK 联网自动下载**
  （`android.builder.sdkDownload=false`），否则它会在
  `RemoteRepoLoaderImpl.fetchPackages` 处静默挂起十几分钟。
  副作用是正面的：万一真缺组件，会立刻报出明确错误而不是静默挂起。

### 桌面端（macOS）

桌面版是**可直接运行的交付物**，已打包在仓库根目录：

```
dist/MoodGarden-macOS-0.2.1.zip     # 18 MB（44 MB 的 .app 压缩后）
```

解压后双击 `mood_garden.app` 即可（通用二进制，Intel 与 Apple Silicon 都能跑）。
它只是把 `build/` 里的产物挪到稳定位置——`build/` 会被 `flutter clean` 清掉。
`dist/` 已加入 `.gitignore`，避免把二进制提交进版本库。

重新构建：

```bash
flutter build macos --release
ditto -c -k --sequesterRsrc --keepParent \
  build/macos/Build/Products/Release/mood_garden.app \
  dist/MoodGarden-macOS-0.2.1.zip
```

**两点说明：**

1. macOS 不是 PRD 的目标平台，加它只是为了能在这台机器上做真实运行验证
   （它与 iOS 同用 Foundation 目录 API + Keychain，是最接近 iOS 的可用环境）。
2. **只能在这台 Mac 上启动**：本机构建是 ad-hoc 签名且 `TeamIdentifier=not set`，
   拷到别的 Mac 会被 Gatekeeper 拦下。
   另有一个已定位的现象：若钥匙串里存在**旧签名**写入的条目，
   首次访问会弹系统授权框（点「允许」即可）。清掉旧条目后不再弹：
   ```bash
   security delete-generic-password -s flutter_secure_storage_service \
     -a mood_garden_master_key
   ```
   这是桌面签名问题，**不影响 iOS**（始终以 team 签名 + data protection keychain）。
