# 迭代路线图

本文档与 PRD 第 13 章「里程碑规划」对齐。

> ⚠️ PRD 中三个阶段的**时间节点均为占位性规划**，原文注明「具体日期需在项目启动后进一步确认」。
> 因此本文档以「完成标准」而非日期来定义阶段边界——日期待项目正式启动后补充。

---

## 阶段一：MVP 验证期

**阶段目标**（PRD 13）
> 验证「种花 + 烧纸卷」核心机制是否成立，能否形成用户情感联结与留存。

**PRD 定义的核心内容**：花园首页、记录开心事 / 不开心事、种子落地动画、点燃燃烧动画、时光轴基础版本（P0 功能）。

### 当前进度

| 交付项 | 状态 | 备注 |
| --- | --- | --- |
| 花园首页 | ✅ 骨架完成 | 全景画布 + 今日概览 + 养分进度条 + 双主入口 |
| 记录开心事 | 🟡 部分 | 文字 / 标签 / 日期已完成；**图片输入待实现** |
| 种子落地反馈动画 | 🟡 占位 | 动效节奏完整，需替换为手绘插画 |
| 记录不开心事（情绪纸卷） | 🟡 部分 | 文字已完成；**图片输入待实现** |
| 点燃 / 燃烧动画 | 🟡 占位 | 长按仪式与灰烬逻辑完整，需替换美术资源并接入音效 |
| 时光轴（周 / 月 / 年 + 日期详情） | ✅ 骨架完成 | 含「已转化为养分」封条 |
| 快捷标签输入 | ✅ 完成 | 6 个预设标签 |
| 本地加密持久化 | ✅ 完成 | AES-256-GCM + Keychain / Keystore 托管密钥 |
| 无障碍（字体放大） | ✅ 完成 | 2× 字体下全部页面零溢出，有回归测试 |
| 图片输入 | ⛔ 未开始 | 加密存储已就位；图片密文方案与 burn 时的文件清理尚未设计 |

### MVP 收尾必须完成的事

- [x] **接入本地加密持久化** —— 数据加密落盘，密钥由系统安全区托管
- [x] **无障碍：字体放大 2× 零溢出**（PRD 第 10 章）
- [x] **图片选择与图片加密存储** —— 拍照 / 相册 / 多图，燃烧时连同密文删除
- [x] **燃烧与种子入土的轻音效** —— 链路已通，素材为合成占位音
- [x] **色彩对比度达到 WCAG AA**（PRD 第 10 章）
- [ ] 替换三处占位动效为手绘插画资源（**需美术产出**）
- [ ] 用正式音效素材替换占位音（**需声音设计产出**）
- [ ] 内置圆体字体（**需字体选型**）
- [ ] 完成 iOS 真机走查（本机模拟器子系统不可用）
- [ ] 花种与标签对照表定案后补全完整清单

### 阶段完成标准

- 用户能完整走通「记录开心事 → 看到种子入土 → 隔天回来看到花开」；
- 用户能完整走通「写下不开心 → 长按点燃 → 看到灰烬入土 → 养分增加」；
- 杀进程重启后数据仍在，且存储文件无法被直接读出明文；
- 关闭网络不影响任何核心功能（纯本地）。

## 阶段二：功能完善期

**阶段目标**（PRD 13）
> 完善养成深度与个性化体验，提升长期留存。

**PRD 定义的核心内容**：花之图鉴、主题换肤、每日提醒（P1 功能），优化动画细节与性能表现。

### 当前进度

| 交付项 | 状态 | 备注 |
| --- | --- | --- |
| 花之图鉴 | ✅ 完成 | 三个分区 + 稀有度 + 收集进度 + 隐藏款解锁条 |
| 主题换肤 | ✅ 可用 | 4 个主题可自由切换并持久化 |
| 每日提醒 | ✅ 完成 | 本地通知，文案按日期轮换、刻意不带催促感 |
| 动画细节与性能优化 | 🟡 部分 | 花园渲染已设上限并去掉逐帧分配；动效待美术资源 |

### 本阶段待办

- [x] 每日提醒（提醒时间可配置；文案内置四句温和文案轮换）
- [x] 自定义快捷标签的增删改
- [x] 进阶收集玩法补全：进化花种解锁、季节限定约束、隐藏款规则
- [x] 性能预算：花园渲染上限 + 去掉逐帧对象分配
- [x] 无障碍：字体大小调节、色彩对比度（PRD 第 10 章）
- [ ] 花朵详情页（当前图鉴卡片不可点入）
- [ ] 提醒文案风格做成可选项（待产品定义）

## 阶段三：正式上线期

**阶段目标**（PRD 13）
> 面向全量用户正式发布，完善生态与传播能力。

**PRD 定义的核心内容**：分享功能（P2）、无障碍与隐私安全体系建设、正式市场推广。

### 本阶段待办

- [ ] 分享中心（花园全景 / 图鉴分享至社交平台）
- [ ] 隐私安全体系：本地加密审计、云同步授权机制、隐私政策
- [ ] 账号体系与云同步（是否支持游客模式待产品决策）
- [ ] 云同步的数据冲突策略（多端同时记录同一朵花）
- [ ] 商业化探索（主题皮肤 / 稀有花种），需评估与治愈系调性的兼容性
- [ ] 崩溃监控与异常恢复机制
- [ ] Android 版本评估（PRD 第 10 章：视用户增长与市场反馈考虑拓展）
